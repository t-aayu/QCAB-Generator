# Changelog

All notable changes to **QCAB Generator** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-22

### Added
- **Step 1 — Test Configuration:** Optional Test Name / Footer Stamp, live miniature A4 margin preview card, and question count configuration (1–20) with quick UPSC presets (`1`, `5`, `10`, `20`).
- **Step 2 — Question Details Editor:** Dynamic add/remove questions, mutually exclusive question text and Photo Picker image attachment, Clear & Undo controls, customizable Marks Stamp, Pages Required stepper, and empty-question confirmation dialog.
- **Step 3 — Native A4 QCAB PDF Engine & Preview:** Official `210 × 297 mm` A4 PDF generation with `25 mm` double margins, bundled PT Serif typography, justified text layout, aspect-ratio-fitted diagrams/equations, right-margin exam warning, and native `PdfRenderer` preview with Save to Downloads, Save As, and Share PDF.
- **Theme Switcher:** Top-level System / Light / Dark mode switcher defaulting to System and persisted with Jetpack DataStore Preferences.
- **App Polish:** Custom adaptive QCAB booklet launcher icon, edge-to-edge inset handling, and bundled `PT Serif` & `Inter` typography.
